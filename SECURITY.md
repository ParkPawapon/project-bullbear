# Security policy

Report suspected security vulnerabilities through [GitHub private vulnerability reporting](https://github.com/ParkPawapon/project-bullbear/security/advisories/new). Include the affected commit, impact, and steps to confirm the issue. Omit credentials, keys, personal data, and unrelated files.

Give the maintainer time to investigate before public disclosure. Use ordinary GitHub issues for non-security bugs. The scope includes the current Java desktop foundation, its distribution, and the CI pipeline.
